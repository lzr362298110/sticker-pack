# 表情包画风卡

用户上传的风格参考优先。只有角色图且用户未指定画风时，按角色类型给 2–4 个合适的选项，用编号、名称和可见画法解释差别。选定后把画法转成自然语言，完整写进每张静态提示词。正式生图输入是角色图和提示词。

| 编号 | 画风 | 可直接转写的画法 |
|---|---|---|
| 01 | 极简线条 | 圆润轮廓和稀疏内线，点眼、短弧嘴，用姿态与少量动作线表达情绪。 |
| 02 | 粗线色块 | 粗黑外线略有起伏，内线少，硬边平涂，大眼白配小瞳孔，肢体动作明显。 |
| 03 | 暖色手绘 | 暖灰棕线、低饱和暖色，毛发分成几簇，局部轻纹理，保留宠物花纹和耳形。 |
| 04 | 动漫 Q 版 | 大头短身、干净外线、眼睛有清晰高光，发束分组，少量分层阴影。 |
| 05 | 平涂头像 | 胸像正面或微侧，轮廓用相邻大色块区分，配色集中，配字简短。 |
| 06 | 柔光 3D | 大头短身、圆润体积、宽柔高光，转折处用渐变暗部，材质纹理集中于服饰或毛发。 |
| 07 | 像素贴纸 | 用清楚的阶梯边缘和有限色阶，五官用像素簇，夸张剪影保持小尺寸可读。 |
| 08 | 手写涂鸦 | 略抖的线、松散的手写字、简化肢体，文字围绕动作疏密排布。 |

背景、是否配字和景别按用户选择确定。角色身份和辨识点取自原图。风格卡可结合用户上传的参考调整。
