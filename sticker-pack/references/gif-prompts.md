# 单格 GIF 提示词

## 每格提示词

文件名沿用格号，如 `02-R2C3.txt`。将定稿的 240×240 单格 `02-R2C3.png` 作为图像输入。根据静态画面和表情含义选一项清楚的主动作，再按需加一项细节动作。动作适合角色肢体和画幅。写之前确认 GIF 背景，静态背景只作为参考。选择透明时，每条首句写「生成一个透明背景的循环 GIF」。选择有底时，在首句说明用户选定的底色或场景。

```text
生成一个透明背景的循环 GIF。
用附图作为角色、画风和构图参考，从附图姿态开始：[起始姿态]。
[主动作及节奏]，随后[回到起始姿态的动作]，首尾自然衔接。
镜头固定。全程保留[角色特征、配色、描边和构图]，主体之外保持真正透明。
[有字：原文“收到”全程清楚，保持原位置和样式。无字：保持全程无字。]
动作、道具和文字都留在画面安全边界内。
```

例「收到」可以抬手敬礼、眨眼，再放下手回到起点。「困了」可以缓慢合眼、轻点头，再抬回原位。用户回传单格 PNG 或 GIF 并反馈动效时，核对格号、原定稿和问题所在的动作或时间段。仍以定稿 PNG 为起始参考，把用户意见写成该格完整的新提示词，保留已认可的动作、文字、画风和背景。只交该格的新提示词及参考上传顺序。平台接受动图参考时，可把回传 GIF 作为次要动作参考。

## 可选的 GPT Image 2.6 API 参数

用户选择 GPT Image 2.6 API 时，可另附参数供用户自行调用。每格一条请求，使用图像编辑接口，传单格 PNG 和该格提示词。建议起始参数如下。其他平台使用通用提示词，参数按其能力填写。 [GIF 生成指南](https://developers.openai.com/api/docs/guides/image-generation#generate-animated-gif-output) · [图像编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)

```json
{
  "model": "gpt-image-2.6-sunburst",
  "output_format": "gif",
  "n": 1,
  "size": "512x512",
  "frame_count": 9,
  "frame_duration_ms": 200
}
```

9 帧乘 200 ms 是约 1.8 秒的起点，可按动作调整。生成后的 GIF 可在最终整理阶段转为 240×240。
