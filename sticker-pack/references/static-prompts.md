# 静态九宫格和返修提示词

[OpenAI 官方 GPT Image 2.6 提示词指南](https://developers.openai.com/api/docs/guides/image-prompting?model=gpt-image-2.6)

## 整套规划

按 [画风提示词结构](static-planning.md#画风提示词结构) 拆解参考，先展示参考图的借鉴摘要和本套逐格方案。分析摘要可以标明风格来源。正式提示词逐条写出角色辨识点、画法、精确台词、背景和文字摆放。把同一套可执行的画风文字完整写入每张提示词。Codex 代生图与仅交提示词使用同一份内容，生图输入只包括用户角色图与提示词。

## 每张九宫格的提示词结构

替换所有括号内容，展开九条格位。用户已指定文字时逐字保留。只有多张用户角色图才编号并注明各自的角色用途。出稿前按只输入角色图的条件复核提示词能否独立使用。

```text
生成一张 1:1 的聊天表情贴纸图，3 行 3 列，共 9 个独立表情。
以我上传的角色照片或角色原图为辨识依据。
九格中是同一个角色，保留[脸、花纹、发型、服装、配饰等关键特征]。
整套共用画法。[媒介观感、景别、头身比例和轮廓]。[外线、内线或无描边时区分轮廓的方法]。[眼鼻嘴的形状及夸张方式]。[主体色、点缀色、填色、明暗及质感]。[动作幅度、主体占格、符号和配字规则]。
输出背景使用[用户确认的透明背景、指定颜色或具体场景]。
每格等宽等高，行列规则对齐。格间有清晰空隙。角色、动作、道具和文字完整留在各自格内，四周有安全留白。
第 1 行第 1 列：[表情 + 动作 + 道具。文案“准确文字”仅一次，具体位置与处理，例如靠视线侧的小气泡或手持牌面]。
第 1 行第 2 列：[同上]。
第 1 行第 3 列：[同上]。
第 2 行第 1 列：[同上]。
第 2 行第 2 列：[同上]。
第 2 行第 3 列：[同上]。
第 3 行第 1 列：[同上]。
第 3 行第 2 列：[同上]。
第 3 行第 3 列：[同上]。
保持九格的角色、画风和字形一致，动作轮廓和表情清楚有区别。文字按每格所写的位置排布，给字和动作各留足空间。画面中只出现指定文案，不绘制格位编号、总标题或水印。
```

无字版改为明确要求全图无字，删掉格位里的文案要求。用户指定其他画幅时同步修改。静态背景先向用户确认，代生图和仅交提示词都适用。把确认的背景写进每张提示词。选择透明时写「透明背景」，明确贴纸外围和格间使用实际透明像素，并在工具支持时开启透明输出。选择纯色时写明颜色，选择场景时写明每格的背景安排。API 参数单列，直接调用 2.6 时显式指定 `gpt-image-2.6-sunburst` 或用户指定的 `gpt-image-2.6-flare`。通过 Image API 编辑接口输入角色图。多张角色图的顺序、画幅和建议输出格式另附。平台未知时给通用上传说明。用户选择具体平台或模型后，另附对应可用参数。1:1 静态图可用 size=1024x1024 与 output_format=png。每张使用各自的提示词，单次请求只生成一张。

## 局部修改提示词

```text
编辑图 1 中这张已生成的九宫格。图 1 是当前版本的编辑底图。[图 2 是原角色参考，若需要。]
只修改第[行]行第[列]列里的[动作、表情、配字或其他具体区域]。
把[旧内容]改成[准确的新内容]。[有字时逐字写出新文案及原位置。]
该格沿用[从原提示词提取的角色辨识点、线条、色彩、五官和字形等适用规则]，保留[该格已认可的动作或排版]。另外八格沿用图 1 的画面、文字和位置。保持原有画幅、格距和可裁切留白。
```

若用户修改整套风格，更新共用设定，标记受影响的图并重新审阅。对局部返修逐一比对其他格，发现漂移时用同一底图收紧修改范围。把确认的版本和格位对应起来。
