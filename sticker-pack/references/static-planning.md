# 静态表情策划与参考图分析

## 从参考图提炼可执行的画法

### 先找决定画风的特征

1. 实际查看用户上传或选定的图库图。先看缩小后留下的剪影、比例、主色和明暗，再看眼口、轮廓边缘、阴影和文字的近景细节。参考是整套表情时，比较多格，区分反复出现的画法和某一格专用的动作、道具、表情或排字。
2. 找出最能改变成图观感的几项，先写它们，再补能指导落笔、上色或构图的细节。使用相对描述，例如外线比内线粗一档、眼白大而瞳孔小、阴影只落在头部下缘。具体比例、色值、材质和制作工艺只有看得出或用户指定时才写；必要时用「近似」「看起来像」说明证据范围。
3. 多张参考分别记录借哪项特征，再合成一套画法。同一维度有冲突时优先用用户指定的来源；如果没有优先级，且选择会明显改变观感，就请用户确认。图库图打不开时注明信息来自图库描述。用户上传的图无法查看且缺少描述时，请用户补传或说明画法。
4. 向用户展示「图里观察到什么 → 这套怎么画」的摘要。角色的脸型、花纹、耳形、发型和服装等取自原角色图。参考图的角色、台词、道具和页面元素要分别判断，只有用户明确希望复用的具体内容才带入。底色、字与版式采用本轮已确认的需求。

### 画风提示词结构

按下表扫一遍可观察维度。只把看得出、和成图相关、适用于本套的项写进最终提示词。缺项可以省略，画风标签可作为总述，后面紧跟实际画法。将定下来的规则分成「整套共用」和「逐格变化」。每张独立提示词都写全共用画法，动作、道具、文案和局部位置按格变化。

| 模块 | 提示词写法 |
|---|---|
| 媒介与整体表现 | 先定画面的二维或立体感及边缘观感，例如平面图标、手绘卡通、像素画、柔光玩偶渲染。用具体证据解释「手绘」「复古」等标签，例如略抖的墨线、受限配色或可见颗粒。 |
| 大形、比例与辨识 | 写剪影的圆方尖、几何概括方式、景别、头与身的相对大小、肢体长短和视觉重心。分开写角色应保留的辨识点，以及可以夸张或简化的结构。 |
| 线条与边缘 | 写有无描边、线色、内外线的粗细层级、转角和线尾、连续或断开、平滑或略抖。无明显描边时，写清轮廓靠相邻色块、明暗反差还是光线分离。 |
| 五官与表情机制 | 写眉眼、眼白、瞳孔、高光、鼻口和腮红的形状与相对位置。说清主要靠瞳孔位移、嘴型变形、身体压缩或肢体动作来表达情绪，给不同情绪留出明显差异。 |
| 配色与填色 | 写角色固有色与画风的用色规则，例如暖色主调、点缀只占小面积、强弱对比、纯色硬边或渐变。必要时指定点缀色分别用在腮红、符号或道具上。 |
| 明暗、光线与质感 | 写有无阴影、明暗层次、影边软硬及纹理位置。有立体感时描述高光宽窄、材质反射和可见光线方向。手绘、像素或平涂风则按实物观察决定写颗粒、阶梯边缘或均匀填色。 |
| 动作、构图与文字 | 写姿态幅度、动作线与图形符号的密度、主体占格比例及裁切留白。配字时写字形、字重、描边或气泡、与主体的距离，并按格安排侧排、弧排、举牌或上下留白。无字时用动作与符号承担表达。 |
| 一致性与简化 | 用明确取舍锁定容易跑偏的地方，例如「外线稳定偏粗、五官内线稀少、只有颊色和道具用高饱和色」。指出哪些元素可以随场景变化。 |

### 两种画法的转写示例

- **图库 #51 粗线色块风，套到浅金白长毛狗。** 可见特征是略抖的粗黑线、少量平涂色、大眼小瞳孔和夸张动作。可写成「用略带起伏的粗黑外线，内线集中在耳根、爪缝和嘴角。胸毛用几段圆弧概括。浅金耳朵和奶白额纹用硬边纯色块分开，小面积珊瑚粉作腮红。眼白画成大圆，小黑瞳孔随视线移动。惊讶时身体后仰、前爪撑开。短句用粗黑手写字，跟着动作放在留白里」。
- **图库 #21 柔光 3D 大头贴纸，套到同一角色。** 可见特征是大头短身、柔和体积明暗、材质细节与白色贴纸边。可写成「采用大头短身的圆润立体比例，浅金耳朵和奶白胸毛用柔软成簇的绒毛概括。脸颊受光处明亮，耳根与胸毛转折处用柔和的渐变暗部。用宽柔高光表现圆润体积，外侧留一圈薄白贴纸边，贴纸外部按用户选定的背景输出」。

### 出稿前检查

删去画风标签、参考名称、图片编号和链接，剩下的文字仍应能指导模型画出有辨识度的轮廓、用色和细节。如果某句只剩「可爱」「高级」「同款」，补上能看到的形状、位置、粗细或明暗。检查多张提示词中的共用画法是否相同，各格变化是否符合主题，以及生成端只收到角色图和这一条提示词时是否仍能直接执行。

## 按五个角度选题

场景回答「在哪种情境发」，功能回答「发这张要做什么」，情绪决定「怎样表现」，人群决定「用谁的说话方式」。热梗是可选的文案素材。把这些维度当作可混搭的索引，向用户展示与当前角色最相关的几项，也接受用户自定义。无需让用户逐项填表。

### 情绪表达

- 惊讶震惊。瞪眼、目瞪口呆、后仰、吓一跳。
- 疲惫摆烂。躺平、困倦、瘫倒、放空、灵魂出窍。
- 尴尬无语。汗流浃背、沉默、僵笑、冷场。
- 疑惑迷茫。歪头、问号脸、摸不着头脑。
- 嘲讽阴阳。冷笑、挑眉、翻白眼、反话。
- 期待渴望。搓手、星星眼、探头、眼巴巴。
- 恐惧紧张。发抖、缩肩、心虚、慌张。
- 自信得意。挑眉、昂首、摆酷、拿捏、稳了。
- 感动治愈。感激、抱抱、鼻酸、暖心。
- 无聊佛系。发呆、摊手、随便、都行。
- 其他可混入开心、委屈、生气、害羞、嫌弃和好奇。

### 聊天功能

打招呼、回复确认、赞同支持、拒绝否定、感谢道歉、夸奖鼓励、催促提醒、请求帮助、调侃吐槽、安慰关心、互动邀请、结束对话。实用聊天套组可以用功能排九格，让相邻的格子能用于不同对话。

### 人物身份或人群

打工人、学生、情侣、单身人士、家长、老板、程序员、设计师、销售客服、老师、玩家、健身党、吃货、铲屎官、追星族、中老年人、社恐或社牛。人群决定处境和语气。例如设计师的「又一版」可以用文件叠满桌，程序员的「修好了」可以用抱着刚恢复的电脑。涉及用户的身份，以用户选择为准。

### 网络梗的候选方向

抽象发疯、互联网嘴替、职场梗、反差搞笑、夸张文学、影视游戏等流行文化。用户可以自带一句，也可以授权联网找。静态分类中的词只说明梗的类型。

## 收集文案偏好与使用热梗

- 问题合并成一轮，集中确认还缺的风格、场景、是否配字、张数和静态背景。有字时补齐语言与文案来源。只上传宠物照时，可用「画风选极简线条、手绘保留毛色或粗线色块。主题选萌宠生活、日常聊天、打工吐槽或自定。要不要配字？做几张九宫格？静态底选透明、纯色还是小场景？」
- 用户提供台词时逐字采用，保留原有标点、方言和语言。用户可以指定格位，未指定时按含义匹配。只给部分台词时，确认剩余格是由用户补齐、交给你拟稿还是留白。用户已给出补齐方式时直接采用。
- 用户选普通文案时，按角色口吻和聊天用途拟短句。用户允许混搭时，可以用指定台词做主，其余按约定补齐。
- 用户明确想要近期热梗后才做联网检索。结合目标地区、语言、社群或平台及当前日期，优先查原始帖子或公开可核实的用例。向用户给出少量候选、适用语境及来源，能确认时间时注明。区分近期正在使用的梗、常青梗和自创改写。联网不可用或热度难以核实时，说明依据，用常青或自创文案，避免把它们标为近期热梗。
- 「你定」允许你按当前角色、使用场景和参考图做选择，并说明选择。未经选择的联网热梗保持可选。

## 逐格策划配字

每格记录格号、聊天用途、表情、动作、台词和文字位置。多张图可以分主题或人群，一起检查意思、表情和动作轮廓是否重复。人物与宠物都要用符合其造型的动作。

配字跟着画面安排。举牌、手机或杯套可以承载短字，疑问适合放到视线侧，冲刺口号可以顺着运动方向，嘀咕可用小气泡，喊话适合靠近张开的嘴，较长文案用空白较多的上下角落。底部配字也是选项，适用于下方留白明显或用户要统一排版。用户未指定统一排版时，根据参考图和每格动作选择位置，避免每格机械使用同一位置。统一字形、线条与色彩即可保持整套一致。

给用户展示时可用短表格，每张写主题和九个编号。示例：

| 格号 | 用途 | 表情与动作 | 文案 | 文字位置 |
|---|---|---|---|---|
| R1C1 | 打招呼 | 抬爪挥手 | 早呀 | 沿挥爪方向放在头像左上方 |
| R1C2 | 确认 | 挺身举牌 | 收到 | 放到前爪举起的小牌上 |
| R1C3 | 困倦 | 蜷成一团、闭眼 | 晚安 | 放在右侧月牙下方的留白区 |

每格的角色、文字、道具、气泡及装饰留在格内。检查耳朵、手势与文字互相避让，浅色背景和透明背景上都考虑对比度，聊天缩小后仍能读。无字版可用姿态和少量图形表达差异。然后按 [静态提示词模板](static-prompts.md) 展开每张图的九格指令。
