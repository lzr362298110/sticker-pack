## 切分

Python 3.9+，依赖 Pillow 10+。调用下面的命令时，将路径替换成实际位置。脚本把输出写在 `--out-dir` 下的编号子目录内，使用新的目录可保留不同版次。传入的裁切坐标以应用 EXIF 方向后的图为准。

规则等分的图：

```sh
python scripts/split_grid.py "sheets/02-v3.png" --sheet 02 --out-dir "cuts/v3" --size 240
```

非等分网格或有明显外边距、宽格间距时，先在图上量出每列和每行可裁切的区间，按从左到右和从上到下填写。坐标右边界和下边界不含在内。下面的命令演示了留边和间隙。

```sh
python scripts/split_grid.py "sheets/02-v3.png" --sheet 02 --out-dir "cuts/v3" --size 240 --x-ranges 12:332 350:670 688:1008 --y-ranges 15:334 352:672 690:1010
```

检查九格都正确对应且没有夹带相邻格。若原图某个主体跨格，先请用户确认如何修复原图，再切分新版本。按比例缩放到 240×240 的正方画布。格内若有留白不足，先核实实测裁切范围和成品预览。透明底用透明补边，实色图用与底色匹配的补边。核对九张尺寸、完整文字和透明通道。宿主无法处理文件时，可交付实测坐标及命令供用户运行。


## GIF 尺寸整理

用户选择这一步后，核对回传文件名和格号。ZIP 先解到独立的工作目录。用户要求整包且文件缺失时列出缺项，齐备后交付整包。用户只要求整理部分 GIF 时，按选定的格号处理。支持传入 GIF 文件或包含 GIF 的文件夹：

```sh
python scripts/resize_gifs.py "gifs-returned" --out-dir "gifs-240"
```

脚本逐个处理动图，按原画布比例使用 Lanczos 缩放并居中补边，保留有意义的帧时长、循环次数及二值透明。量化后相同的连续帧可能合并，合并时长等于原有时长之和。检查动图在浅底与深底上都能播放，轮廓及文字清晰，尺寸是 240×240，并用同编号打包输出。原始 GIF 单独保留。该尺寸与平台体积限制是两项要求，只有用户给出平台要求时才进一步优化体积。
